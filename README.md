# Tide Social

An interactive front-end prototype combining multi-channel social publishing with AI-assisted content operations.

## Run

```sh
python3 -m http.server 4173 --directory outputs/tide-social
```

Open `http://127.0.0.1:4173`.

## Included

- Unlimited simulated social-account connections across 12 platforms, including any number of Instagram handles, LinkedIn profiles/pages, and Threads accounts
- Cross-channel composer with autosaved drafts and scheduling
- Calendar, approval queue, unified inbox, analytics and editable brand brain
- Connection-health states, visible publishing status and media preflight copy
- Cookie preferences plus privacy, cookie, terms and security notices
- Responsive keyboard-accessible UI with reduced-motion support

This is a product prototype. Real OAuth, publishing, analytics ingestion, AI generation, billing, email, media processing and backend security require server-side integrations and platform app approvals.
