# Tide Social — Native Mobile App (React Native & Expo)

A production-grade, native mobile application for **Tide Social** built with **React Native (0.76)**, **Expo (SDK 52)**, and **Expo Router**.

---

## 📱 Features

- **Bottom Tab Navigation**: 5 native tabs (Home, Schedule, Compose FAB, Inbox with badges, Profile).
- **Executive Home Dashboard**: Live 2x2 metric cards with trend indicators, system health status, and quick approval reviews.
- **Content Calendar & Scrubber**: Native weekday pill scrubber and scheduled queue cards.
- **Creative Post Composer**: Multi-channel publisher with AI hook generation.
- **Unified Social Inbox**: Real-time cross-network DM/comment feed with lead intent tagging.
- **Profile & Workspace Hub**: Team seat administration, Pro subscription limits, and Model Context Protocol (MCP) server configuration.

---

## 🚀 How to Run Locally

### 1. Install Dependencies
```bash
cd react-native-app
npm install
```

### 2. Start the Expo Dev Server
```bash
npx expo start
```

### 3. Open on Your Device
- **Physical iPhone / Android**: Download the **Expo Go** app from the App Store or Google Play and scan the QR code.
- **iOS Simulator**: Press `i` in the terminal to launch on Xcode iOS Simulator.
- **Android Emulator**: Press `a` in the terminal to launch on Android Studio Emulator.
- **Web Preview**: Press `w` to open in browser.
